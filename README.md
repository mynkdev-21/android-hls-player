# Android HLS Player

A lightweight HLS/M3U8 stream player for Android built with ExoPlayer (Media3).

## Features
- Play HLS (M3U8), MP4, and direct stream URLs
- Quality selector (Auto, 1080p, 720p, etc.)
- Live stream detection with blinking LIVE indicator
- Brightness & volume gesture controls
- Recent URLs history
- Picture-in-Picture support
- Watch progress saving

## Requirements
- Android 7.0+ (API 24)
- Internet permission

## Usage
1. Clone the repo
2. Open in Android Studio
3. Build & run

## Built With
- [Media3 ExoPlayer](https://developer.android.com/media/media3/exoplayer)
- Kotlin + Java
